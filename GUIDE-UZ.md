# NW CINEMA — telefon orqali joylash (beta)

## 1. Yangi token oling
@BotFather -> /revoke -> botni tanlang -> YANGI TOKENni Notes'ga saqlang.
Tokenni hech kimga (menga ham) yubormang.

## 2. ZIP'ni oching
Telefonda "Fayllar" (Files) ilovasida ZIP'ni bosib turing -> "Ochish / Extract".
Ichida 13 ta fayl chiqadi (Dockerfile, package.json, render.yaml, *.ts ...).

## 3. GitHub
1. github.com -> ro'yxatdan o'ting (Sign up).
2. "+" -> New repository. Nomi: nw-cinema. **Private** tanlang. Create.
3. "uploading an existing file" havolasini bosing.
4. Hamma ochilgan fayllarni birdan tanlab yuklang (13 ta).
5. Pastda "Commit changes" bosing.
Agar telefonda tugma ko'rinmasa: brauzerda "Desktop site" (Kompyuter versiyasi) yoqing.

## 4. Render
1. render.com -> "Get started" -> GitHub bilan kiring.
2. New + -> **Blueprint** -> nw-cinema repository'ni tanlang.
3. BOT_TOKEN so'ralganda YANGI tokenni qo'ying. Boshqa hech narsa shart emas.
4. Apply bosing. 5-10 daqiqa kuting.
5. Logs'da "NW CINEMA ishga tushdi" yozuvi chiqsa, tayyor.

## 5. Sinov
Telegramda botga /start yozing. Birinchi javob ~1 daqiqa kechikishi mumkin (server uyg'onadi).

## Eslatmalar
- Bepul baza ~30 kundan keyin o'chadi (beta uchun).
- Mini App tugmasini bossangiz, hozircha "Tez orada..." sahifasi ochiladi.
- Xato chiqsa, Render -> Logs'dagi matnni menga yuboring (TOKENsiz).
